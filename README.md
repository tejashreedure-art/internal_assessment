
# The Gourmet Haven - Restaurant Website

A fully responsive, single-page website for a fictional upscale restaurant, "The Gourmet Haven." This project showcases modern web development techniques using semantic HTML5, advanced CSS3 with Flexbox and Grid, and vanilla JavaScript for interactivity. The design is elegant, professional, and optimized for all screen sizes.

### [Live Demo] : https://tejashreedure-art.github.io/internal_assessment/

## Features

-   **Fully Responsive Design:** Adapts seamlessly to mobile, tablet, and desktop screens.
-   **Semantic HTML5:** Well-structured and accessible markup for better SEO and maintainability.
-   **Modern CSS Layouts:** Utilizes Flexbox and CSS Grid for complex, robust layouts.
-   **Interactive Menu:** A detailed 36-item menu with images, descriptions, and prices.
-   **Animated "Special of the Day" Section:** A glowing, animated highlight for the chef's special.
-   **"Reserve a Table" Modal:** A pop-up form for table reservations, built with HTML, CSS, and JavaScript.
-   **Smooth Scrolling & Navigation:** A sticky navigation bar with smooth scrolling to all sections.
-   **Scroll-to-Top Button:** A convenient button for easy navigation back to the top of the page.

## Tech Stack

-   **Frontend:**
    -   HTML5
    -   CSS3 (Variables, Flexbox, Grid, Animations)
    -   Vanilla JavaScript (DOM Manipulation, Event Listeners)

## Getting Started

To run this project on your local machine, follow these steps:

### Prerequisites

-   A modern web browser (like Chrome, Firefox, or Edge).
-   A code editor (like VS Code).

### Installation

1.  **Clone the repository** (or download the ZIP file):
    ```sh
    git clone https://github.com/tejashreedure-art/internal_assessment.git
    ```

2.  **Clone the repository** (or download the ZIP file):
    ```sh
    git checkout Restaurant_project
    ```
3.  **Navigate to the project directory:**
    ```sh
    cd project
    ```
3.  **Open the `index.html` file** in your web browser. That's it! The website is fully static and requires no build process.
